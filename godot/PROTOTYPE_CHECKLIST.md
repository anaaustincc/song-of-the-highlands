# First 3D Prototype Checklist (Godot 4)

Keep this first prototype small and finishable.

## Milestone 1: Movement + Camera
- [ ] Create a basic third-person player controller
- [ ] Add a follow camera
- [ ] Confirm the player can move around a tiny test area

## Milestone 2: Interaction
- [ ] Add one interaction button (for example: `E`)
- [ ] Show a simple on-screen prompt near the NPC

## Milestone 3: Dialogue
- [ ] Create one short dialogue UI panel
- [ ] Trigger dialogue when interacting with the NPC
- [ ] Allow closing dialogue and returning to movement

## Milestone 4: Village Test Scene
- [ ] Build one very small village scene (path + one home area)
- [ ] Place one NPC in the scene
- [ ] Play from start to finish: move, interact, read dialogue

## Definition of done (first prototype)
- [ ] A new player can launch the scene and understand what to do
- [ ] Core loop works: walk -> interact -> dialogue
- [ ] Scope remains intentionally small and beginner-friendly
